# Contributing

Use Python 3.11+ and Node 22. Install with `python -m pip install -e '.[dev]'` and `npm install`. Run pytest, Ruff, npm test and npm run build before a pull request. Include tests for accounting, replay and absent telemetry when changing adapters. Never commit private session logs, prompt text or credentials. Keep capability documentation honest and cite upstream sources. Open an issue describing the source format and minimal metadata-only reproduction before substantial integration work.
